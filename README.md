# Cybersecurity Blue Team, Cloud Security, EDR & Forensics Labs

A practical collection of **hands-on cybersecurity and CTF labs** focused on defensive security, endpoint detection and response (EDR), cloud workload protection, container security, network discovery, TLS auditing, public-code reconnaissance, and digital forensics.

The collection brings together exercises involving security monitoring platforms, endpoint protection, cloud security tools, forensic investigation, and network-security utilities.

## Introduction

These labs are useful for cybersecurity students, CTF players, SOC analysts, blue team practitioners, security researchers, incident responders, and learners building practical defensive-security skills.

Key areas include:

- Blue team and defensive security
- Endpoint detection and response
- Cloud workload security
- Container security
- Threat detection and investigation
- Network discovery and security auditing
- TLS/SSL security assessment
- Public-code reconnaissance
- Browser-cache forensics
- Windows Registry forensics

> **Safety:** Perform security testing only in authorized environments or against systems for which you have explicit permission.

## Learning Path

A structured approach to this collection can be:

1. **Start with reconnaissance** using Grep.app.
2. **Learn network discovery** with Nmap.
3. **Study TLS security** with testssl.sh.
4. **Build endpoint-security skills** through the Elastic Defend and SentinelOne labs.
5. **Explore cloud and container security** with CrowdStrike, Wazuh, and Datadog exercises.
6. **Practice forensic analysis** using browser-cache and Windows Registry labs.
7. **Connect detection with investigation** by documenting observations, evidence, indicators, and defensive actions.

## How to Use the Labs

1. Choose a lab from the index.
2. Read its objective, scope, and instructions.
3. Work exclusively within the authorized lab environment.
4. Record relevant findings and security observations.
5. For defensive labs, document detection signals, investigation steps, and evidence.
6. For forensic labs, preserve context and document artifacts carefully.
7. Review the security lesson after completing each exercise.

Do not scan, enumerate, access, or test systems outside the authorized scope of a lab.
